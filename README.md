
# Student Management System

A simple and efficient Student Management System built with Python. This project allows users to manage student records and store student information in a JSON file.

## 📌 Features

- Add new students
- View student information
- Update student records
- Delete student records
- Store student data in JSON format
- Organize code using separate Python modules

## 📁 Project Structure

```text
Student-Management-System/
│
├── main.py
├── utils.py
│
└── database/
    └── students.json
```

## 🛠️ Technologies Used

- **Python** – Main programming language
- **JSON** – Data storage format

## ⚙️ Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/your-repository.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Student-Management-System
   ```

3. Run the application:

   ```bash
   python main.py
   ```

## 📂 File Description

| File | Description |
|---|---|
| `main.py` | Main entry point of the application |
| `utils.py` | Contains utility functions for student management |
| `database/students.json` | Stores student information in JSON format |

## 💾 Data Storage

Student information is stored in `students.json`. The application uses JSON to save and manage student records.
